## Entity Definitions

### GalleryImage

Representa una imagen o GIF corporativo gestionado desde el panel admin y mostrado en la sección "Imágenes de la Empresa" del sitio público.

| Field | Type | Required | Description | Validation |
|-------|------|----------|-------------|------------|
| id | string (UUID v4) | Yes | Identificador único | Generated on creation |
| filename | string | Yes | Nombre del archivo en disco (ej: `a1b2c3d4.webp`) | Sistema genera nombre único |
| originalName | string | Yes | Nombre original del archivo subido | Max 255 chars |
| mimeType | string | Yes | Tipo MIME | Enum: `image/jpeg`, `image/png`, `image/webp`, `image/gif` |
| sizeBytes | number | Yes | Tamaño del archivo optimizado en bytes | Max 10 MB (10,485,760 bytes) |
| width | number | No | Ancho en píxeles de la versión display | Calculado por Sharp |
| height | number | No | Alto en píxeles de la versión display | Calculado por Sharp |
| displayOrder | number | Yes | Posición en la galería (0 = primero) | Integer >= 0, único |
| createdAt | string (ISO 8601) | Yes | Fecha y hora de subida | Auto-generated |
| updatedAt | string (ISO 8601) | Yes | Fecha y hora de última modificación | Auto-updated |

**Storage**: Metadatos en `backend/src/data/gallery.json`. Archivos físicos en `backend/uploads/gallery/`.

**File naming convention**: `{uuid}.{ext}` donde `ext` es `webp` para imágenes estáticas y `gif` para GIFs.

**Image variants generated by Sharp**:
- **display** (1200px width, 80% quality, WebP) — usado en el grid/mosaico público
- **thumb** (400px width, 70% quality, WebP) — usado para lazy loading placeholder
- **original** — solo para GIFs (no se convierten a WebP; se comprimen si es posible)

**Lifecycle**: `created` → (opcional: `replaced` actualiza filename y atributos) → `deleted` (archivo físico eliminado + entrada JSON removida)

**Ordering**: Array ordenado por `displayOrder` ascendente. Al insertar, se asigna `max(displayOrder) + 1`. Al reordenar (drag & drop), se recalculan los `displayOrder` de todos los elementos afectados.

### ProductInfo

Información estática sobre los productos de exportación, visible en el panel admin como referencia.

| Field | Type | Required | Description | Validation |
|-------|------|----------|-------------|------------|
| id | string | Yes | Identificador único | kebab-case slug |
| name | string | Yes | Nombre del producto | Non-empty, max 100 chars |
| category | string | Yes | Categoría del producto | Non-empty, max 50 chars |
| description | string | Yes | Descripción del producto | Non-empty, max 500 chars |
| displayOrder | number | Yes | Orden de visualización | Integer >= 0 |

**Storage**: `backend/src/data/products.json` — archivo estático definido en desarrollo.

**Lifecycle**: Estático. No modificable desde el panel admin. Solo se actualiza con nuevos despliegues.

### ContactMessage

Representa un mensaje enviado desde el formulario de contacto. Es una entidad transitoria: no se persiste en el servidor, solo se transmite por correo electrónico.

| Field | Type | Required | Description | Validation |
|-------|------|----------|-------------|------------|
| name | string | Yes | Nombre del remitente | Non-empty, min 2 chars, max 100 chars, trimmed |
| email | string | Yes | Correo electrónico del remitente | Valid email format (RFC 5322), max 254 chars |
| message | string | Yes | Contenido del mensaje | Non-empty, min 10 chars, max 2000 chars, trimmed |
| timestamp | string (ISO 8601) | Auto | Fecha y hora de envío | Server-generated on receive |

**Storage**: Ninguno. Se envía por correo a ntcdelnorte@gmail.com vía Nodemailer y se descarta.

**Subject format**: `"Consulta web - {name}"`

### AdminSession

Sesión del administrador en el panel. Estado en memoria del backend.

| Field | Type | Description |
|-------|------|-------------|
| token | string (UUID v4) | Token de sesión (almacenado en sessionStorage del frontend) |
| createdAt | string (ISO 8601) | Momento de autenticación |
| lastActivity | string (ISO 8601) | Último momento de interacción con el panel |
| expiresAt | string (ISO 8601) | `lastActivity + 30 minutos` |

**Timeout**: Si `Date.now() > expiresAt`, la sesión se invalida y el siguiente request al panel recibe HTTP 401, forzando re-autenticación con PIN.

**Storage**: En memoria del proceso Node.js (Map con limpieza periódica de sesiones expiradas). No requiere persistencia — si el servidor se reinicia, el admin simplemente vuelve a ingresar el PIN.

```
  [CTRL+J]         [PIN valid]          [30 min inactivity]
  --------> Prompt --------> Active ----------> Expired
                |
                + [PIN invalid] --> Prompt (error message)
```

## Concurrency

Solo un administrador a la vez. El archivo `gallery.json` se lee y escribe atómicamente usando el patrón:
1. Leer `gallery.json` → objeto en memoria
2. Modificar objeto
3. Escribir a archivo temporal `gallery.tmp.json`
4. Renombrar atómicamente `gallery.tmp.json` → `gallery.json` (operación atómica del SO)

Esto previene corrupción si dos operaciones coinciden (la última escritura gana, consistente).
